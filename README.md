# КордонПлан

Консольний MVP, який аналізує дані системи "Електронна черга перетину кордону" з data.gov.ua і підказує, коли та через який пункт пропуску їхати.

## Дані

Джерело: https://data.gov.ua/dataset/a8909a08-4da6-49c5-9238-6ab227059c51

У наборі є два CSV-ресурси:

- `queue.csv` - вантажні автомобілі;
- `busQueue.csv` - автобуси.

Поточні CSV можна скачати з меню програми або покласти вручну в папку `data/`. Для аналізу 6-12 місяців використайте пункт меню "Скачати архівні ревізії CSV" або додайте кілька місячних CSV у `data/`.

## Запуск GUI

```bash
python gui.py
```

GUI відкриває окреме вікно з фільтрами, рекомендаціями, таблицею середніх очікувань, профілем завантаженості та кнопками збереження результатів.

## Запуск консолі

```bash
python main.py
```

Python 3.10+ достатньо для основного функціоналу. Для PNG-візуалізації встановіть `matplotlib`:

```bash
python -m pip install matplotlib
```

## Структура

- `main.py` - консольне меню;
- `gui.py` - графічний інтерфейс;
- `data_loader.py` - завантаження, читання й нормалізація CSV;
- `analytics.py` - розрахунки середнього очікування, рекомендацій і профілю завантаженості;
- `report.py` - текстові звіти, CSV-експорт і PNG-чарти;
- `data/` - CSV-файли;
- `reports/` - збережені звіти та візуалізації.

## Функціонал MVP

- зчитування реальних CSV з data.gov.ua;
- робота з архівом CSV за кілька місяців;
- середній час очікування за схемою пункт x день тижня x місяць;
- введення напрямку, дати та типу транспорту;
- рекомендація пункту пропуску й оптимального дня;
- профіль завантаженості: пікові та тихі дні/місяці;
- збереження результатів у TXT/CSV;
- опційна PNG-візуалізація.

## Як рахується очікування

Для завершених записів використовується різниця `createdDateTime -> exitDateTime`. Якщо `exitDateTime` відсутній, програма пробує `entryDateTime`. Скасовані та неповні записи не входять у середні значення.
